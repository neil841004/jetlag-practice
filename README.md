# Jet Lag 練唱室

在瀏覽器裡練唱 Simple Plan《Jet Lag》的練習台：原曲 / 伴奏即時切換、小節格、循環練習、
困難段落標記、變速不變調、升降 Key。

## 兩種用法

### A. 本機（這台電腦，音檔放在同一個資料夾）

雙擊 **`start.bat`**（會自動開瀏覽器），或：

```bash
node serve.js 8123
```

> ⚠️ 不要直接雙擊 `index.html` —— `file://` 的安全限制會讓它讀不到音檔，
> 一定要透過 `start.bat` 這個本機小伺服器開啟。

### B. 網頁版（GitHub Pages，任何一台電腦）

打開網址 → 第一次會請你**選自己電腦上的那兩個音檔** → 之後就記在那台電腦的瀏覽器裡
（IndexedDB），不用再選，也不需要網路。

**音檔不在這個 repo 裡**，原因有兩個：

1. 這是商業錄音，放進公開 repo 等於公開散布。
2. 59 MB 每次造訪都要重抓，改成本機選檔反而更快。

歌詞同理（版權），由你自己貼上（見下方「歌詞」）。

> 把練習成果搬到另一台電腦：在原本那台按 **設定 → 匯出設定檔**，
> 在新的那台選好音檔後按 **設定 → 匯入設定檔**，
> 歌詞、翻譯、段落、困難標記、對齊微調就全部跟著過去。

需要：Chrome / Edge（或任何支援 AudioWorklet 的瀏覽器）。本機版另需 Node.js（沒有會自動改用 Python）。

## 歌詞

程式沒有內建歌詞（版權）。兩種方式之一：

1. **網頁裡貼**（推薦）：按右上 **歌詞編輯** →
   - 「貼上歌詞」頁：左邊貼英文（一行一句）、右邊貼中文翻譯（行數對齊）。
     **可以直接從歌詞網頁整段複製貼上** —— 勾選「自動清除」會把 `[Verse 1]`、`[Chorus]`
     這類段落標記（轉成分句空行）以及 `12 Contributors`、`You might also like`、`Embed`
     等頁面雜訊清掉。如果手上是 `.lrc` 檔，整份貼進去，時間標記會自動帶入，一步完成。
   - 沒有時間標記時，換到「打拍同步」頁：按播放，每句開頭按 <kbd>Enter</kbd> 抓時間，
     按錯用 <kbd>Backspace</kbd> 退回；也可以直接改數字、或按 ⟲ 設成目前播放位置。
     - **對拍**：可選「半拍 / 整拍」，手按的時間會自動吸到拍點上，結果整齊很多。
     - **全部時間一起移動**：手按通常會慢個 100ms 左右，整首抓完後用 −100ms / −20ms
       一次把所有句子往前挪，邊播邊調到順為止。
   - 「匯入 / 匯出」頁可以 **下載 lyrics.json**，蓋掉這個資料夾裡的同名檔案，
     以後換瀏覽器也不用重做。
2. **直接編輯 `lyrics.json`**：
   ```json
   { "version": 1, "lines": [ { "t": 13.82, "en": "...", "zh": "..." }, { "br": true } ] }
   ```
   `t` = 該句開始秒數（以原曲為基準），`br` = 空行。

## 操作

| 鍵 | 功能 |
|---|---|
| <kbd>空白</kbd> | 播放 / 暫停 |
| <kbd>←</kbd> <kbd>→</kbd> | 前後一小節（<kbd>Shift</kbd> 四小節、<kbd>Ctrl</kbd> 換段落） |
| <kbd>1</kbd>…<kbd>9</kbd> | 直接跳段落 |
| <kbd>V</kbd> | 人聲 開 / 關（原曲 ↔ 伴奏） |
| <kbd>H</kbd> | 歌詞顯示：歌詞+全部翻譯 → 只顯示當句翻譯 → 關閉 |
| <kbd>C</kbd> 或 <kbd>L</kbd> / <kbd>[</kbd> <kbd>]</kbd> / <kbd>Esc</kbd> | 循環開關 / 設起迄點 / 清除框選 |
| <kbd>D</kbd> / <kbd>N</kbd> | 標記困難小節 / 跳下一個困難處 |
| <kbd>↑</kbd> <kbd>↓</kbd> | Key ±1 半音（不變速） |
| <kbd>+</kbd> <kbd>−</kbd> | 速度 ±10%（100% → 50%，不變調） |
| <kbd>0</kbd> | 速度與 Key 歸零 |

滑鼠：總覽軸或小節格上 **點擊** = 跳播、**拖曳** = 框選循環段（自動對齊小節）、
小節格 **右鍵 / Ctrl+點擊** = 標記困難小節。

所有標記與設定（困難小節、循環、速度、Key、音量、對齊微調、段落、歌詞）
都存在這台電腦的瀏覽器 localStorage（鍵名 `jetlag.practice.v1`），關掉再開會還原。

## 兩軌對齊

兩個音檔原本沒有對齊，實測結果：

* 伴奏（`Jet Lag無人聲.wav`）比原曲（`Jet Lag.mp3`）**晚 2.825 秒**
  （伴奏開頭多了 4 拍 count-in），整首一致、沒有漸進漂移（測量誤差 ±15 ms）。
* 兩軌 **速度與調性相同**（交叉相關的最佳時間比例為 1.0000，頻譜移位 0 cent）。

程式已自動補償這 2.825 秒，切換人聲時播放位置不會跳。
兩者是不同的錄音版本，所以切換時音色會有差異，這是音檔本身的差別。
若你覺得還差一點點，右上 **對齊** 面板可以 ±1 ms 微調（會記住）。

## 小節格線

實測 **BPM 145.0**（4/4），第 1 小節起點 **0.582 秒**，全曲 **120 小節**。
段落表是用自相似矩陣 / 新奇度曲線自動偵測的結果（11 段），
不一定完全符合你的習慣 —— 右上 **段落** 面板可以改名稱、起始小節、顏色分類。
BPM 與第一小節位置也可以在 **對齊** 面板微調。

## 技術說明

變速與移調互相獨立，都在 `js/stretch-worklet.js` 的 WSOLA（波形相似重疊相加）引擎裡完成：

* 每個 synthesis hop 輸出 1024 樣本、來源前進 `速度 × 1024` → 控制速度
* frame 內以 `2^(半音/12)` 的步距重新取樣 → 控制音高
* 在理想位置 ±14.5 ms 內搜尋與前一 frame 尾端最相似的接點（先 8 倍抽樣粗搜、再全取樣細修），
  Hann 窗 50% overlap-add（窗和恆為 1，不會有音量起伏）
* 速度 100% 且 Key ±0 時完全跳過搜尋，overlap-add 等於原樣重建 → 原音無損

兩軌共用同一條時間軸、各自用自己的 offset 讀樣本，所以切換人聲只是 70 ms 的增益淡入淡出，
位置與節奏完全不受影響。
